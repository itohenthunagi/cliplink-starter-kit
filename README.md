# Cliplink 導入キット — はじめにお読みください

**画面を撮ると、すぐに共有用のURLができる**アプリです。Gyazo と同じように、撮った画像をURLで相手に送れます。矢印や黒塗りを入れたり、あとから共有を止めたりもできます。

このキットは、あなたのPCに合わせて **Claude Code と会話しながら組み立てる** ための材料一式です。プログラムの知識は要りません。Claude Code が質問しながら、一つずつ一緒に進めます。

## 用意するもの

| 必要なもの | 説明 |
|---|---|
| Claude Code | デスクトップアプリでも、ターミナル版でも可 |
| Windows 10/11 または Mac | どちらでも使えます |
| Cloudflare のアカウント | 共有URLのページを置く場所。無料プランで使えます |
| 画像の保管先 | Cloudflare R2・Dropbox・Googleドライブのどれか。どれがよいかは、セットアップの最初に比べて選べます（詳しくは `docs/storage-options.md`） |

Node.js（アプリを動かす土台）が入っていなくても大丈夫です。Claude Code が確認して、入れ方を案内します。

## はじめかた

### 配布のメッセージにURLが書かれている場合（おすすめ）

Claude Code を開き、配布のメッセージに書かれた文章をそのまま送ってください。Claude Code がキットを取ってきて、置き場所の相談からセットアップまで進めます。GitHub のアカウントは要りません。

### ZIPファイルを受け取った場合

1. ZIPを右クリック →「すべて展開」（Mac はダブルクリック）で展開します。
2. できたフォルダを、次のような場所に移します。**Dropbox・OneDrive・Googleドライブ・iCloud の中には置かないでください**（アプリの記録ファイルが同期されると壊れることがあります）。
   - Windows：`C:\Users\<あなたの名前>\apps\`（無ければ `apps` フォルダを作る）
   - Mac：ホームフォルダの中の `apps`
3. Claude Code でそのフォルダを開きます。
4. 「**セットアップを始めて**」と送ります。

途中でやめても大丈夫です。次に「セットアップの続きをして」と送れば、記録から再開します。所要時間は、保管先によって30分〜1時間ほどです。

### 受け取ったあとの管理

配布元（`https://github.com/itohenthunagi/cliplink-starter-kit`）は配布専用で、あとから更新されることはありません。受け取ったキットは、あなたのものとして自由に管理・改造してください。

- 配布元とのつながりは、セットアップのはじめに Claude Code が外します（配布元から何かが入ってくることはありません）。
- 自分の GitHub に置いて管理する場合は、**非公開（Private）のリポジトリ**にしてください。セットアップ後は、あなたの Cloudflare の設定やセットアップの記録が入るためです（合言葉の `.env` は GitHub に送られない設定になっています）。
- よく似た名前の別のリポジトリを見かけても、使わないでください。正式な配布元は上のURLだけです。

## セットアップで決めること

1. アプリの名前（管理画面や共有ページの上に出ます。Cliplink のままでも可）
2. 画像の保管先（比べ方は Claude Code が表で説明します）
3. 共有URLの名前（`https://この部分.pages.dev/…` になります）
4. ショートカットキー（Windows は、どの画面からでもキー1つで撮影できます）

## 安全のために知っておいてほしいこと

- 画像やあなたの情報が、このキットを作った人やリベシティに送られることはありません。保存されるのは、あなたのPCと、あなたが選んだ保管先、あなたの Cloudflare だけです。
- 共有URLは「URLを知っている人なら誰でも見られる」しくみです。社外秘や個人情報が写った画像は共有しないか、黒塗りしてから共有してください。
- セットアップが終わると、このフォルダの `.env` というファイルに、あなた専用の「合言葉（接続情報）」が保存されます。**セットアップ後のフォルダを、人に渡したりZIPにして送ったりしないでください。** 人に配るときは、このキットの元のZIPを渡します。

詳しくは `docs/security.md`（安全についての説明）を読んでください。

## このフォルダの中身

**あなたが読むのは、このファイルと `docs` フォルダの説明書だけです。** ほかのファイルは Claude Code が使うものなので、開いたり動かしたりしなくて大丈夫です。

| 名前 | 何のためのものか | 開いてよいか |
|---|---|---|
| `README.md` | このファイル（はじめにお読みください） | 読んでください |
| `docs/` | 説明書のフォルダ。使い方・安全・保管先の比べ方など | 読んでください |
| `CLAUDE.md` / `AGENTS.md` | Claude Code（と Codex など）への作業指示書。AIが最初に読みます | 読むのは自由。書き換えない |
| `.env.sample` | 設定の見本。セットアップで、あなた用の `.env` が作られます | 触らない |
| `src/` | アプリ本体のプログラム | 触らない |
| `scripts/` | セットアップや撮影を手伝う小さなプログラム | 触らない |
| `tests/` | アプリが正しく動くかを確かめるためのプログラム | 触らない |
| `migrations/` | 共有の記録（台帳）の表の作り方 | 触らない |
| `pages/`、`wrangler.jsonc` | Cloudflare に置く共有ページの設定 | 触らない |
| `package.json`、`package-lock.json` | アプリに必要な部品の一覧 | 触らない |
| `SPEC.md` | アプリの設計図。機能を足すときに Claude Code が読みます | 読むのは自由 |
| その他の `.json` / `.ts` で終わるファイル | 道具の設定 | 触らない |

### 見慣れないファイルの種類について

| 末尾 | 中身 |
|---|---|
| `.ts` | **動画ではありません。** TypeScript というプログラムの言葉で書かれた文字のファイルです。Windows では動画のアイコンで表示されることがありますが、ダブルクリックすると動画アプリが開こうとするだけなので、開かないでください |
| `.md` | 説明書。メモ帳などでも読めます |
| `.json` / `.jsonc` | 設定を書いた文字のファイル |
| `.cs` / `.ps1` | Windows のショートカットキー機能のためのプログラム |
| `.sql` | 記録（台帳）の表の作り方 |
| `.html` / `.css` | 管理画面の見た目 |

### セットアップ後に増えるもの

| 名前 | 中身 |
|---|---|
| `.env` | あなた専用の合言葉（接続情報）。**人に見せない・渡さない** |
| `node_modules/` | アプリの部品置き場（数百MB）。消しても Claude Code が入れ直せます |
| `dist/` | 組み立てた管理画面 |
| `.cliplink/` | 設定と記録（ログ） |
| `docs/my-setup.md` | あなたのセットアップ内容の記録（合言葉は書かれません） |

## 困ったとき

このフォルダで Claude Code に、そのまま言葉で聞いてください。「共有URLが開かない」「ショートカットが効かない」「〇〇できるようにしたい」など、言い方は自由です。
