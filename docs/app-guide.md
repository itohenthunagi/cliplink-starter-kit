# アプリの使い方

管理画面は http://127.0.0.1:4317 （`PORT` を変えた場合はその番号）。以下、表示名は `CLIPLINK_APP_NAME` で決めた名前に置き換えて読んでください。

## 起動と終了

- 起動：このフォルダで `npm start`（画面のコードを変えた後は先に `npm run build`）。Claude Code に「アプリを起動して」でも可。
- 終了：起動したターミナルで Ctrl+C。
- Windowsで常駐ショートカットを入れている場合は、キーを押すと自動で起動し、最後の操作から5分で自動的に止まります。

## 画像・動画を登録する

どの方法でも、登録した瞬間に共有URLが付きます（ブラウザが許可すればクリップボードにもコピーされます）。

| 方法 | 操作 |
|---|---|
| 範囲を撮影 | 「▣ 範囲を撮影」または Ctrl+Shift+S（Mac: ⌘+Shift+S）→ 画面・ウィンドウ・タブを選ぶ → 範囲をドラッグ（「全体を保存」も可） |
| 画面録画 | 「◉ 画面録画」 |
| ファイル | 「＋ ファイルを追加」、またはファイルをドラッグ |
| 貼り付け | OSの範囲撮影でクリップボードにコピー → 管理画面で Ctrl+V（Mac: ⌘+V） |
| Windowsのキー | 常駐ショートカット導入時。初期値 Ctrl+Alt+S（撮影）/ Ctrl+Alt+R（録画） |
| コマンド | `npm run import -- "<画像の絶対パス>" --title "題名"`（サーバー起動中） |
| 長いWebページ | `npx playwright install chromium` を一度実行後、`npm run capture:web -- "https://..."` |

ブラウザでの撮影には、画面共有の許可（Macは「画面収録」の許可）が必要です。

## 整える

- **注釈を付ける**：矢印・番号・文字・黒塗り。黒塗りは公開画像の画素として書き出されます。
  - 「保存して共有URLに反映」：同じURLの表示が注釈付きに変わる
  - 「作業版として保存」：共有中の内容は変えずに残す
- **版の履歴**：どの版を共有URLに出すか選べます。古い版に戻すことも可能。原本は常に残ります。
- 一覧で「未反映の編集あり」と出ている画像は、共有URLにまだ出していない版がある印です。

## 共有する

- 詳細の最上部にある共有URLの「コピー」で送ります。
- **まとめて共有**：公開中の画像を複数選ぶと、順番と説明付きのひとつのURLにできます。
- **共有を停止**：そのURLと画像のURLが開けなくなります。相手がすでに保存したものは回収できません。「同じURLで共有を再開」で戻せます。
- セットアップの途中（共有ページを公開する前）は、共有URLがこのPCの中でしか開けません。公開後に登録した画像から、スマホや相手のPCで開けるようになります。

## 整理する

- タイトル・タグ・メモ・日付で検索できます。
- **削除から保護する**：誤操作防止。公開中・保護中の画像は「保管済み」に移せません。
- **保管済み**：一覧から外す操作です。アプリはファイルを消しません。

## AIと一緒に使う

詳細の「AI参照情報をコピー」で、その画像の識別子と手元のファイルの場所を取得できます。Claude Code などで画像を加工したら、結果は別ファイルに保存し、次のコマンドで作業版として登録します（共有中の内容は変わらないので、画面で確認してから反映します）。

```sh
npm run import -- "<加工後の画像の絶対パス>" --asset-id "<対象の識別子>" --ai
```

## 制限

- 1ファイル100MBまで。録画は95MB付近で自動停止を試みます。
- 共有URLは「リンクを知っている人なら閲覧可能」。パスワード・期限・閲覧者ごとの権限はありません。
- Cloudflare と保管先には無料で使える量の上限があります（`docs/security.md` の「お金がかかる条件」）。

## ファイルの置き場所

- 画像：PC内の保存フォルダの `assets/<画像ID>/` の中（元の画像・編集版・共有版に分かれています）。同じものが保管先にも置かれます。ファイル名は変わらないので、画像の名前は管理画面で変えます。**保管先やこのフォルダの中のファイルを手で消したり名前を変えたりしないでください**（共有URLの画像が見えなくなります）。
- 設定と記録：`.cliplink/`。共有の記録（台帳）そのものは Cloudflare に置かれます。
