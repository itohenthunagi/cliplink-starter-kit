# 安全についての説明

「知らないうちに画像が漏れないか」「お金がかからないか」を心配する方のための説明です。わからないところは、Claude Code に「この部分をもっとやさしく説明して」と聞いてください。

## 1. 画像と情報はどこに置かれるか

| 置き場所 | 置かれるもの | 見られる人 |
|---|---|---|
| あなたのPC | 撮った画像（元の画像・編集した画像）、設定、合言葉（`.env`） | あなただけ |
| あなたが選んだ保管先（R2・Dropbox・Googleドライブ） | 画像の写し | あなただけ（アプリ専用の場所に置かれ、一般公開はされません） |
| あなたの Cloudflare | 共有ページのプログラムと、共有の記録（画像のタイトル・共有中かどうか） | 共有URLを知っている人が、共有中の画像だけを見られます |

- このキットを作った人、リベシティ、Anthropic（Claude の会社）に、画像や記録が送られるしくみはありません。
- アプリのプログラムはすべてこのフォルダにあり、中身を誰でも確認できます。

## 2. 共有URLは誰が見られるか

- 共有URLは `https://〇〇.pages.dev/s/` の後ろに、32文字のでたらめな英数字が付いた形です。推測して当てることは、事実上できません。
- ただし **URLを知っている人なら誰でも見られます。** 相手がURLを転送すれば、転送先の人も見られます。パスワードや期限は付きません。
- 共有ページは、Google などの検索結果に出ないように設定しています。
- **社外秘・個人情報（名前、メールアドレス、電話番号、会員情報など）が写った画像は、共有しないでください。** どうしても必要なら、アプリの「注釈を付ける」→「黒塗り」で隠してから共有します。

### 黒塗りのしくみ

黒塗りは、共有用の画像そのものを黒く塗りつぶして作ります。相手が画像を保存したり加工したりしても、下の文字は復元できません。黒塗り前の元の画像は、あなたのPCと保管先に残ります（共有URLからは見えません）。

## 3. 共有を止めるには

アプリで画像を開き「**共有を停止**」を押すと、その瞬間から共有URLも画像のURLも開けなくなります。「同じURLで共有を再開」で戻すこともできます。

相手がすでに保存・スクリーンショットした画像は、取り消せません。

## 4. 合言葉（接続情報）の扱い

セットアップでは、保管先や Cloudflare とつなぐための「合言葉」が、このフォルダの `.env` というファイルに保存されます。家の合鍵のようなものです。

- **チャットに貼らない。** セットアップ中の入力は、Claude Code が開く「このPCの中だけで動く入力ページ」で行います。Claude Code が合言葉を聞いてくることはありません。もし「ここに貼って」と言われたら、断ってください。
- **人に渡さない。** `.env` ファイル、セットアップ後のフォルダ、それをZIPにしたものを、人に送らないでください。
- **パスワードは入力しない。** 各サービスへのログインや2段階認証は、あなたがブラウザで直接行います。Claude Code にパスワードを教える必要はありません。

### もし合言葉が漏れたかもしれないと思ったら

Claude Code に「合言葉が漏れたかもしれない」と伝えてください。次の手順を一緒に行います。

| 保管先 | 取り消し方 |
|---|---|
| Dropbox | Dropbox の設定 →「接続済みのアプリ」から、このアプリの接続を解除 |
| Googleドライブ | Google アカウントの「サードパーティ製のアプリとサービス」から、このアプリのアクセスを削除 |
| Cloudflare（R2を含む） | 共有ページの管理用の合言葉を作り直して、設定し直す |

取り消したあとは、セットアップの接続手順をやり直せば元どおり使えます。

## 5. 管理画面は外から入れない

管理画面のアドレス `http://127.0.0.1:4317` の `127.0.0.1` は「このPC自身」という意味です。同じWi-Fiの人も、インターネットの向こうの人も、あなたの管理画面には入れません。

## 6. 各サービスに渡す権限は最小限

| サービス | アプリができること | できないこと |
|---|---|---|
| Dropbox | 専用フォルダ（「アプリ」フォルダの中）の読み書き | ほかのファイルを見る・消す |
| Googleドライブ | このアプリが作ったファイルの読み書き | ほかのファイルを見る・消す |
| Cloudflare R2 | このアプリ専用の置き場の読み書き | ほかの置き場を触る |

## 7. お金がかかる条件

| サービス | 無料の範囲 | 超えたとき |
|---|---|---|
| Cloudflare の共有ページ | 1日10万回の表示まで | その日は表示できなくなる（自動で課金はされません） |
| Cloudflare の共有の記録（D1） | 5GBまで（画像そのものは入らないので、まず超えません） | 記録できなくなる |
| Cloudflare R2（選んだ場合） | 10GBまで | 超えた分だけ課金（1GBあたり月約2円）。R2を使い始めるときにカードの登録が必要 |
| Dropbox（選んだ場合） | 2GB（無料プラン） | 保存できなくなるだけ。課金されない |
| Googleドライブ（選んだ場合） | 15GB（Gmailなどと合わせて） | 保存できなくなるだけ。課金されない |

このキットのセットアップで、有料プランに申し込む操作は行いません。R2 の申し込み（カード登録）が必要な場合は、あなたが Cloudflare の画面で行います。

## 8. やってはいけないこと

- セットアップ後のフォルダ・`.env` を人に渡す
- 合言葉やパスワードをチャットに貼る
- 社外秘・個人情報が写った画像を、黒塗りせずに共有する
- 保管先の専用フォルダの中のファイルを、手で消したり名前を変えたりする（共有URLの画像が見えなくなります）

## 9. 全部やめたくなったら

Claude Code に「このアプリを全部やめたい」と伝えれば、手順を案内します。おおまかには次のとおりです。

1. アプリで共有中の画像をすべて「共有を停止」する
2. Cloudflare の管理画面で、共有ページのプロジェクト（と R2 を使った場合はその置き場）を削除する
3. 保管先で、このアプリの接続を解除する（上の「取り消し方」の表）
4. このフォルダを削除する
