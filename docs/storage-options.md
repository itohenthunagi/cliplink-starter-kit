# 画像の保管先の選び方

## まず、しくみ

共有URLを開いた相手に画像を見せているのは、あなたのPCではなく **Cloudflare 上の共有ページ** です。だから、あなたのPCの電源が切れていても、相手は画像を見られます。

そのかわり、共有ページが **インターネット越しに画像を取り出せる場所** に、画像を置いておく必要があります。これが「保管先」です。

たとえると、保管先は「留守番の人に合鍵を預けておける倉庫」です。

- **PCの中だけに置く** のは、倉庫が自宅の中にあって鍵もかかっている状態です。相手は中を見られないので、共有URLを開いても画像が出ません。**このアプリでは選べません。**
- **Cloudflare R2・Dropbox・Googleドライブ** は、合鍵（接続の許可）を共有ページに預けられるので使えます。画像はあなたのPCにも残り、共有用の写しが保管先に置かれます。

## 保管先に必要な条件

| 条件 | なぜ必要か |
|---|---|
| ① 外部のプログラムが、許可をもらって読み書きできる公式のしくみ（API）がある | 共有ページが画像を取り出すため |
| ② その許可を長期間使える | 期限が切れると、共有した画像がある日急に見えなくなるため |
| ③ 無料または手ごろな費用で、十分な容量がある | 画像がたまっていくため |
| ④ そのサービスの利用規約で、この使い方が認められている | 規約違反でアカウントが止まるのを避けるため |

## 3つの選択肢の比べ方

画像1枚は、画面の撮影ならだいたい0.2〜1MBです。下の枚数は1枚0.5MBとして計算した目安です。

| | Cloudflare R2 | Dropbox | Googleドライブ |
|---|---|---|---|
| どんなもの | Cloudflare の中にある画像置き場 | ファイル共有サービス | Google のファイル置き場 |
| 新しく作るアカウント | なし（Cloudflare だけで完結） | Dropbox（無ければ無料で作れます） | なし（Google アカウントがあれば） |
| 無料で使える容量 | 10GB | 2GB（ほかのファイルと合わせて） | 15GB（Gmail・Googleフォトと合わせて） |
| 画像の枚数の目安 | 約2万枚 | 約4千枚 | 約3万枚（ほかの利用分を除く） |
| お金がかかる可能性 | **使い始めるときに支払い方法（カード）の登録が必要。** 10GBを超えた分だけ課金（1GBあたり月0.015ドル、約2円） | かからない。容量がいっぱいになると保存できなくなるだけ | かからない。容量がいっぱいになると保存できなくなるだけ |
| 設定の手間 | いちばん少ない（Cloudflareの画面で申し込みボタンを押すだけ） | 少ない（Dropbox の開発者向け画面でアプリを1つ作る。5分ほど） | 多い（Google Cloud の管理画面で5〜6画面の設定。20〜30分ほど。Claude in Chrome があれば画面操作を手伝えます） |
| 気をつけること | カード登録に抵抗がある人には不向き | 容量が小さい。PCにDropboxアプリを入れている場合は、同期でPCの容量も使う | 設定の最後で「本番」に切り替えないと、**7日で画像が見えなくなる**（手順で必ず行います）。会社の Google アカウントは管理者が止めていることがあるので、個人のアカウントがおすすめ |
| アプリが触れる範囲 | このアプリ専用の置き場だけ | Dropbox の中の専用フォルダ（「アプリ」フォルダの中）だけ | このアプリが作ったファイルだけ |

### おすすめの選び方

- すでに Dropbox を使っている → **Dropbox**
- Google アカウントの容量に余裕がある、カード登録はしたくない → **Googleドライブ**
- 設定をできるだけ簡単にしたい、カード登録してもよい → **Cloudflare R2**
- 迷ったら、Claude Code に「どれがいい？」と聞いてください。使っているサービスを聞いたうえで提案します。

## ほかのサービスを使いたい場合

上の3つ以外でも、ふだん使っているサービスがあれば Claude Code に伝えてください。上の「保管先に必要な条件」に照らして、その場で使えるかどうかと注意点を説明します。使えるものは、Claude Code がアプリに対応を追加できます（少し時間がかかります）。

参考までに、よく名前が挙がるサービスの見立てです。

| サービス | 見立て |
|---|---|
| OneDrive | 条件を満たします。設定は Googleドライブと同じくらいの手間です |
| Box | 条件を満たします。無料プランは1ファイルの大きさに上限があります |
| GitHub | 技術的には置けますが、画像を大量にためる使い方はおすすめしません（保存できる量の目安が小さく、置いた画像を消しても履歴に残り続けるため） |
| iCloud Drive | **使えません。** Apple が、外部のプログラムから iCloud Drive のファイルを読み出す公式のしくみを公開していないためです |
| Googleフォト | **おすすめしません。** 外部のプログラムから読み出せる範囲が限られていて、共有に向きません |
